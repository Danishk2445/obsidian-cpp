# Frozen interfaces

Interfaces other modules/agents build against. Change deliberately and update all users.

## M0
- `oc::ClonePaths` (src/core/config/clone_paths.h): XDG-based clone dirs; per-vault config/data/cache dirs.
- `oc::ConfigStore` (src/core/config/config_store.h): per-vault Obsidian-shaped JSON files, cached, debounced writes.
- `oc::VaultRegistry` (src/core/config/vault_registry.h): `obsidian-cpp.json` vault list + global options.
- `oc::Theme` / `oc::ThemeManager` / `oc::currentTheme()` (src/render/theme/theme.h): token access by Obsidian CSS
  variable name (`color()`, `px()`, `number()`, fonts); `themeChanged()` signal; `generation()` for cache keys.
- `oc::IconProvider` (src/render/theme/icons.h): Lucide/Obsidian icon names → pixmaps/icons.
- `oc::Busy` (src/core/util/busy.h): in-flight work counter for headless idle detection.

(M1 adds oc_text, SyntaxTree, Vault, Document, View/Workspace, Command/Hotkey, Editor facade.)

## M1 (frozen headers — read them, they document the contracts)
- `src/text/*` — `Text` (immutable chunked lines, per-line EOL, CM6 '\n'-joined offsets), `codec` (byte-exact
  UTF-8 with surrogate escapes, `contentHash`), `ChangeSet`/`ChangeDesc` (CodeMirror 6 semantics),
  `Selection`/`SelRange`, `Transaction` (userEvent strings), `History` (CM6 grouping/mapping), `diff`/`merge3`.
- `src/markdown/syntax_tree.h` — `oc::md::SyntaxTree`: incremental block parser API (line roles, container
  markers, preorder block nodes, per-type info, budgets/resume, dump/equivalent).
- `src/core/vault/vault.h` — `Vault`, `TFile`/`TFolder`, `DiskState`, `DocumentStorage` (CAS writes), signals
  `created/modified/deleted/renamed(…, bool external)`, `onlineChanged`, trash modes, ignore rules.
- `src/ui/workspace/{view,view_registry,workspace}.h` — `View`/`FileView`, `ViewRegistry`, `Workspace`/
  `WorkspaceLeaf` (Obsidian getLeaf/openFile/setViewState semantics, workspace.json shape).
  Additive M1 extensions of `Workspace` (for the `workspace:*` commands): `duplicateLeaf`, `newTab`, `nextTab`,
  `previousTab`, `goToTab`, `goToLastTab`, `closeActiveLeaf`, `togglePinActiveLeaf`, `canUndoCloseLeaf`,
  `sideWidth`/`setSideWidth`. Views: `EmptyView` ("empty"), `PlaceholderView` (unregistered types, round-trips
  their state) and `registerCoreViews()` (sidebar placeholders) live in `ui/shell/empty_view.h` and
  `ui/workspace/placeholder_views.h`; internals (model tree, widgets, drag & drop) in `workspace_p.h`.
- `src/core/vault_session.h` — per-vault service bundle (`vault()`, `documents()`, `commands()`, `workspace()`,
  `viewRegistry()`, `config()`), i.e. Obsidian's `app`.

## M2 (frozen)
- `src/markdown/inline_tree.h` — `InlineTree` (preorder nodes in content offsets, Mark children for hideable
  syntax, per-type infos), `LeafContent` (content ↔ document mapping), token precedence rules (header comment).
- `SyntaxTree::leafContent / tableCellContent / inlineTree(...)` — lazy, cached inline parsing per leaf.
- `md::parseInline(content, refdefs)` (inline_tree.h) — pure, thread-safe inline parser; `LinkRefDefinition` lives
  in inline_tree.h. Implemented in `src/markdown/inline_parser.cpp`, lexical rules in `inline_rules.{h,cpp}`
  (internal, not frozen: entity/escape/label helpers, `normalizeLinkLabel()` with full Unicode case folding; refdef
  labels are re-normalized with it on lookup; `InlineNode::flags` = `rules::FlagUrlWww/FlagUrlEmail` for bare
  URLs/autolinks); tables generated by `tools/gen_markdown_tables.py`. The block parser lives in `src/markdown/md_*.{h,cpp}` + `syntax_tree.cpp` (design: `md_engine.h`;
  set `OC_VERIFY_INCREMENTAL=1` to check every incremental update against a full parse).

## Services (stable; additive changes only — read the headers)
- `src/core/vault_session.h` also exposes `metadata()` (MetadataCache), `vaultConfig()` (Obsidian `getConfig`/
  `setConfig` with 1.13 defaults, `configChanged(key)`), `fileManager()`. `src/app/application.cpp`
  (`createServices`, `populateWindow`) shows how a session and a window are assembled; tests copy that recipe
  (see `tests/ui/editor_suggest_test.cpp`).
- `src/core/documents/document_manager.h` — one shared `Document` per path (`acquire`/`release`, LRU of released
  docs, saves on release, follows vault renames/deletes/offline). `src/core/documents/document.h` — `dispatch()`,
  `changed(DocUpdate)` (with `origin` = dispatching view), byte-exact `save()`.
- `src/core/files/file_manager.h` — Obsidian's FileManager: `renameFile` (with link updates + confirmation
  callback), `trashFile` (trashOption), `newFileParent`, `createNewMarkdownFile`, `generateMarkdownLink`.
- `src/core/metadata/metadata_cache.h` — `fileCache(path)` (CachedMetadata), `resolver()` (LinkResolver:
  `resolve`, `linkText`), `resolvedLinks`/`unresolvedLinks`, `backlinksOf`, `tagCounts`, `aliases`, signals
  `changed/deleted/resolved`, `waitUntilClean`. `link_updater.h` (rename rewrites), `subpath.h`
  (`resolveSubpath`: heading/block/footnote line ranges), `link_suggest.h` (editor-suggest triggers, link/heading/
  block/tag suggestions, Obsidian's link replacement, `vaultTags`).
- `src/core/fuzzy/fuzzy.h` (`FuzzyQuery`, `SimpleSearch`), `src/core/search/*` (query parser/AST, `SearchEngine`,
  snippets), `src/core/time/moment_format.h`, `src/core/util/word_count.h`, `src/core/recovery/*` (file recovery).
- `src/core/commands/command_registry.h` — `Command`, `CommandRegistry` (editor provider, hotkeys.json),
  `HotkeyDispatcher` (app-wide; skips widgets inside `ocCapturesKeys` overlays and the navigation keys of an editor

## Editor & UI building blocks (stable; additive changes only)
- `EditorView` (src/editor/editor_view.h): decoration layers (`addDecorationLayer`), folding API (`foldLine`,
  `setFolds`, `foldsChanged`), top widget (inline title), `setVisibleLineRange` (embed a section),
  `caretRectAt`, `documentHeight`, signals `linkActivated(target, kind, newLeaf)` / `linkHovered(target, kind,
  rect)` (kind 0 wikilink, 1 embed, 2 markdown link, 3 url, 4 tag). `editor/search/*` = find/replace logic.
- `EditorHooks` (src/editor/editor_hooks.h), additive: `KeyHandler` / `addKeyHandler` / `runKey` — a key hook run
  first in `EditorView::event` for `ShortcutOverride` (a side-effect-free question: return true to keep the key, the
  view then accepts the override so no application shortcut takes it) and `KeyPress` (true consumes it; unconsumed
  keys continue to the view's own handling, typing still through the Input/Paste hooks). Keys typed into a child of
  the view (its bottom panel) are not offered to the hook. The app's `HotkeyDispatcher` still sees keys first, like
  Obsidian's capture-phase keymap (Obsidian hotkeys keep precedence over vim).
- `EditorView`, additive: `setCursorShape(CursorShape::Bar|Block, mainOnly)` / `cursorShape()` /
  `blockCursorRect(range)` (vim's fat cursor: `--interactive-accent` box, glyph in `--text-on-accent`, on the last
  selected character of a forward selection) and `setBottomPanel(widget)` / `bottomPanel()` / `updateBottomPanel()`
  (a full-width panel docked under the text; the viewport shrinks by its `sizeHint()` height).
- `History` (src/text/history.h), additive: `beginGroup()` / `endGroup()` / `inGroup()` — explicit, nestable undo
  groups (every change recorded while one is open joins one event; vim: one undo step per command and per insert
  session). Undo/redo inside a group starts a new event; closing a group seals it.
- `VimController` (src/editor/vim/vim_controller.h): vim key bindings for one EditorView (Obsidian's "vimMode");
  `MarkdownView` creates it while the option is on (`MarkdownView::vim()`), `setCommandRunner` routes `:w` / `:q` /
  `:wq` / `:x` to `editor:save-file` / `workspace:close`, `modeChanged(Mode)` / `modeName()` / `pendingKeys()` for a
  mode indicator, `feedKeys` / `executeEx` for scripts. Internals in `src/editor/vim/vim_*` (not frozen).
- `src/ui/overlay/suggest_modal.h` — `SuggestModal` (Obsidian's prompt), `SuggestionList`, `PromptInstructions`;
  `overlay_layer.h` — in-window overlays + notices.
- `src/ui/views/markdown/markdown_view.h` — `MarkdownView` (view state `{file, mode, source}`, eState `subpath`,
  `line`, `match{content, matches}`, `rename`, `focus`), static `openLinkText(ws, target, kind, sourcePath,
  newLeaf)` and `setTagHandler`. `editor_suggest.h` (the "[[", "#", "[^" popups), `page_preview.h`
  (`PagePreview::of(window)`: `onLinkHover(source, linktext, sourcePath, globalRect, hoverParent)` for any view
  that shows links; sources: "editor", "preview", "file-explorer", "search", "backlink", "outline", "graph", …).
- Headless driving: `--script <file>` (src/app/scenario_runner.h: open/cursor/type/key/command/wait/screenshot/
  expect-line).
- `src/ui/widgets/tree_list.h` — `TreeList`: Obsidian's generic `.tree-item` list (painted, virtualized, file
  explorer metrics): items (chevron / icon, prefix, title with highlights, sub-text, flair), pane section headers,
  search-result match snippets (matches box, more-context / action buttons, destination chips) and messages;
  states, keyboard navigation, selection, inline rename, drag & drop reordering; clients build `Node`s and call
  `setRoots()` (state carries over by node id), behaviour via `handlers()`.
- `src/ui/views/sidebar/*` — the core plugins' sidebar views ("backlink", "outgoing-link", "tag", "outline",
  "bookmarks", "all-properties"), `registerSidebarViews` / `registerSidebarCommands` (sidebar_registration.h);
  `sidebar_common.h`: `NavHeader` (nav buttons + search filter), `LinkedFileView` (follows the active file unless
  pinned/linked), `readNoteText` / `replaceNoteText`, `searchFor` (tag/property clicks → search view). Pure models:
  `core/metadata/{mentions,tag_tree,outline,property_index}.h`, `core/bookmarks/bookmarks.h` (bookmarks.json,
  `sessionBookmarks(session)`).
- `src/ui/settings/*` — Settings (M7). `settings_modal.h`: `registerSettingsCommands` (app:open-settings, Mod+,),
  `openSettings(window, tabId)`, `SettingsController::of(window)` (vault registry hook, core / community plugin
  switches, live `applyAppearance()` / `applyOptions()`, signals `manageVaultsRequested`, `openHelpRequested`,
  `corePluginToggled`, `communityPluginToggled`, `frameStyleChanged`, `relaunchRequested`), `SettingsModal`
  (sidebar-layout Modal with tabs, sub-pages, search). `settings_tab.h`: declarative `SettingDef` /
  `SettingControl`, `SettingsTab`, `PluginSettingsTab`, `renderSettings`. `setting_item.h`: `SettingItem`
  (Obsidian's Setting: addToggle / addDropdown / addText / addSlider / addButton / addExtraButton /
  addColorPicker / addControl) and `SettingGroup` (cards, lists, search; `setPlain(true)` for ordinary modals).
  `settings_pages.h`: the tabs, `corePluginInfos()`, `css_snippets::*`, `resolveFontList`. `path_suggest.h`:
  `FolderSuggest` (text input + folder popup), `FilePicker` (file combobox). `hotkeys_tab.h`: `HotkeysTab`,
  `HotkeyChip`. Widgets: `ui/widgets/{dropdown,button,color_swatch}.h`.
